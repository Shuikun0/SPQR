## 📜 征服指南 (Usage)

你不必率军翻越阿尔卑斯山，也不必发动第三次布匿战争。

1. **宣战**：直接访问上方链接，或下载后用浏览器打开 `qr-generator.html`。
2. **驻扎**：本地双击或丢在静态托管服务器上均可。它像罗马军团一样坚不可摧，无需后端，由于它是 HTML，它甚至可能比罗马帝国存续的时间还长。

## ⚔️ 军团武库 (Features)

* **万神殿级生成**：
    * **多段方阵**：支持多段文本输入，每段都会独立受封，生成专属的二维码图腾。
    * **全屏威慑**：点击二维码即可进入全屏模式。大，大到让对面的蛮族在五百米外就能扫码投降。
* **鹰旗巡视 (扫码)**：
    * 一键切换至「扫码」行省，调起你的摄像头百夫长。
    * **凯旋归来**：识别结果支持一键复制，情报传递速度比罗马大道上的快马还要快。

## 🛡️ 后勤补给 (Dependencies)
